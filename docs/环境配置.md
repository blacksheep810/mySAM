## 系统要求

### 硬件要求

- **GPU**: NVIDIA GPU（推荐 A30 或更高，至少 24GB 显存）
- **内存**: 建议 64GB 或更多
- **存储**: 至少 100GB 可用空间（用于数据集和模型检查点）

### 软件要求

- **操作系统**: Linux (Ubuntu 20.04+ 推荐)
- **CUDA**: 11.8 或更高版本
- **Python**: 3.10.x
- **Conda**: Miniconda 或 Anaconda

### 当前环境信息

- **Conda 环境名**: `py310env`
- **Python 版本**: 3.10.16
- **PyTorch 版本**: 2.7.0+cu118
- **CUDA 版本**: 11.8
- **GPU**: NVIDIA A30 (24GB)

## Conda 环境配置

### 1. 安装 Miniconda/Anaconda

```bash
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
bash Miniconda3-latest-Linux-x86_64.sh
source ~/.bashrc
```

### 2. 创建 Conda 环境

```bash
conda create -n py310env python=3.10 -y
conda activate py310env
```

### 3. 安装 CUDA Toolkit

```bash
conda install -c conda-forge cudatoolkit=11.8 -y
```

## 项目依赖安装

### 1. 克隆项目仓库

```bash
cd /root/workspace
git clone <repository-url> mySAM_amend
cd mySAM_amend
```

### 2. 安装 PyTorch（CUDA 11.8）

```bash
conda activate py310env
pip install torch==2.7.0 torchvision==0.22.0 torchaudio==2.7.0 --index-url https://download.pytorch.org/whl/cu118
```

### 3. 安装 Segment Anything Model (SAM)

```bash
cd /root/workspace
git clone https://github.com/facebookresearch/segment-anything.git
cd segment-anything
pip install -e .
cd /root/workspace/mySAM_amend
```

**注意**: segment-anything 需安装在 workspace 下独立目录，项目通过 Python 路径引用。

### 4. 安装其他核心依赖

```bash
conda activate py310env

pip install pytorch-lightning==2.5.1.post0 torchmetrics==1.7.2 torchsummary==1.5.1
pip install opencv-python==4.7.0.72 opencv-python-headless==4.11.0.86 albumentations==1.3.1 Pillow
pip install segmentation-models-pytorch==0.3.2 efficientnet-pytorch==0.7.1 fft-conv-pytorch==1.2.0
pip install numpy==1.23.5 pandas scikit-learn scikit-image
pip install tqdm yacs==0.1.8 tensorboard
pip install batchgenerators==0.25.1 batchgeneratorsv2==0.2.3 connected-components-3d==3.23.0 acvl-utils==0.2.5
```

### 5. 完整依赖列表（可选）

```bash
conda activate py310env
conda list --export > environment_conda.txt
pip freeze > requirements.txt
# 新机器: conda install --file environment_conda.txt -y && pip install -r requirements.txt
```

## 快速安装脚本

```bash
#!/bin/bash
set -e
conda create -n py310env python=3.10 -y
conda activate py310env
conda install -c conda-forge cudatoolkit=11.8 -y
pip install torch==2.7.0 torchvision==0.22.0 torchaudio==2.7.0 --index-url https://download.pytorch.org/whl/cu118

cd /root/workspace
[ ! -d segment-anything ] && git clone https://github.com/facebookresearch/segment-anything.git
cd segment-anything && pip install -e . && cd /root/workspace/mySAM_amend

pip install pytorch-lightning==2.5.1.post0 torchmetrics==1.7.2 torchsummary==1.5.1
pip install opencv-python opencv-python-headless albumentations Pillow
pip install segmentation-models-pytorch efficientnet-pytorch fft-conv-pytorch
pip install numpy pandas scikit-learn scikit-image tqdm yacs tensorboard
pip install batchgenerators batchgeneratorsv2 connected-components-3d acvl-utils

mkdir -p checkpoints
[ ! -f checkpoints/sam_vit_h_4b8939.pth ] && wget https://dl.fbaipublicfiles.com/segment_anything/sam_vit_h_4b8939.pth -O checkpoints/sam_vit_h_4b8939.pth
git lfs install
echo "Done. Run: conda activate py310env && python train.py --help"
```

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| **CUDA 不可用** | 检查 `nvidia-smi`，确认 PyTorch 与 CUDA 版本匹配后重装 PyTorch |
| **导入 segment_anything 失败** | 确认在 segment-anything 目录下执行过 `pip install -e .`，且 PYTHONPATH 或工作目录正确 |
| **显存不足 (OOM)** | 减小 `--batch_size`，或使用 `--gradient_accumulation_steps`、`--use_gradient_checkpointing`、`--use_amp` |
| **依赖冲突** | 新建干净 conda 环境，按文档顺序安装 |
| **Git LFS 大文件为指针** | `git lfs install` 后执行 `git lfs pull` |
| **数据路径错误** | 检查 `data/ISIC` 目录结构及 CSV 中 image_file/mask_file 路径 |

## 维护

- **更新依赖**: `pip install --upgrade <package-name>`
- **备份**: `conda env export > environment_backup.yml`，`pip freeze > requirements_backup.txt`
- **恢复**: `conda env create -f environment_backup.yml`，再 `pip install -r requirements_backup.txt`
