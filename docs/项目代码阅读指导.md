# 项目代码阅读指导

本文档帮助快速定位 mySAM_amend 的核心代码与数据流，便于修改、调试和扩展。

---

## 一、目录与入口

### 1.1 根目录与入口脚本

| 路径 | 作用 |
|------|------|
| `train.py` | **训练入口**。解析命令行参数（`config.args.build_argparser`），构造 `Trainer(args)` 并调用 `trainer.train()`。 |
| `model_original.py` | 早期单文件训练脚本，与当前 Trainer 并列，可选使用。 |
| `config/args.py` | 所有命令行参数定义（数据、模型、训练、对比学习、早停、过渡区、强增强、伪 Dice、poor sample 等）。 |

### 1.2 训练主流程入口

- **入口方法**：`training/trainer.py` 中的 `Trainer.train()`（约 1211 行起）。
- **单 epoch 循环**：在 `train()` 内对 `train_loader` 迭代，每个 batch 依次调用：
  - `_prepare_images_and_boxes` → `_teacher_forward` → `_student_forward`（含可选 `_augment_images_student`）→ `_compute_losses`（含可选 `_student_decoder_forward_for_dice`）→ `_compute_contrastive_loss` → backward → `_update_ema_teacher`。

## 二、核心模块与职责

### 2.1 training/trainer.py（训练主逻辑）

**类**：`Trainer`

**主要方法（按调用顺序）**：

| 方法 | 行号约 | 作用 |
|------|--------|------|
| `__init__` | 30 | 设备、模型、优化器、数据加载器、损失函数、EMA、各种开关（如 student_strong_aug, pseudo_dice_weight） |
| `_setup_device` | 140 | CUDA/CPU、多卡 |
| `_setup_models` | 194 | 加载 SAM、创建 Teacher（EMA）、Student encoder 解冻、投影头 |
| `_setup_optimizer` | 231 | 仅优化 encoder + proj 参数 |
| `_setup_dataloader` | 261 | ISIC 数据集与 collate_fn_isic |
| `_prepare_images_and_boxes` | 290 | 图像 resize 到 1024，框坐标按比例缩放到 SAM 尺寸 |
| `_create_box_mask_from_corners` | 321 | 由旋转小框四角点生成特征图分辨率下的二值 mask（用于对比学习） |
| `_augment_images_student` | 86 | 对 Student 输入做强颜色增强（若 `student_strong_aug`） |
| `_teacher_forward` | 356 | Teacher 前向：大框+小框 prompt → mask_logits，并计算熵 |
| `_student_forward` | 432 | Student 前向：encoder → img_emb，ref_feats；decoder(冻结) → pred_logits, pred_iou |
| `_student_decoder_forward_for_dice` | 107 | 用 img_emb（不 detach）经 decoder 得到 pred，供伪标签 Dice 用 |
| `_compute_losses` | 510 | 计算 loss_mask/loss_iou（仅监控）、loss_contrast、loss_distill、loss_dice_pseudo（若启用），以及 batch_miou |
| `_get_adaptive_weights` | 585 | 根据 epoch 与当前 mIOU/TS 一致性返回交集/并集/困难样本权重 |
| `_compute_contrastive_loss` | 672 | **正负样本构建与 InfoNCE**：熵筛选、大小框 mask、过渡区、正负采样、均衡、pixel_info_nce |
| `_update_ema_teacher` | 1153 | EMA 更新 Teacher 参数 |
| `_get_ema_decay` | 1176 | 动态 EMA decay（如 0.97→0.98→0.998） |
| `_save_checkpoint` | 1188 | 保存 checkpoint |
| `_detect_and_save_poor_samples` | 1448 | 表现差样本可视化与记录 |
| `_save_poor_samples_csv` | 1567 | 将 poor samples 写入 CSV |

阅读建议：先看 `train()` 的 batch 循环，再按需进入 `_teacher_forward` → `_student_forward` → `_compute_losses` → `_compute_contrastive_loss`，最后看 EMA 与早停/保存逻辑。

### 2.2 models/（模型与损失）

| 文件 | 内容 |
|------|------|
| `sam_wrapper.py` | `load_sam_model`（加载 SAM、解冻策略）、`create_teacher_model`（深拷贝为 Teacher）、`get_encoder_feature_dim`、`setup_multi_gpu`；依赖 `setup_sam_path()` 将 segment-anything 加入路径。 |
| `projection.py` | `PixelProjHead`：将 encoder 特征投影到对比学习空间（proj_dim）。 |
| `losses.py` | `DiceLoss`（分割/伪标签 Dice）；`pixel_info_nce(anchors, positives, negatives, temperature)`（像素级 InfoNCE）。 |

### 2.3 dataset/ 与 training/data_utils.py

| 路径 | 内容 |
|------|------|
| `dataset/ISIC.py` | `ISIC2016Dataset`：读取 CSV（大框、小框 AABB 或旋转角点）、图像与 mask、缩放坐标；返回 `image, big_box, small_box, mask, img_name, small_box_corners_scaled`（6 元组）。 |
| `training/data_utils.py` | `collate_fn_isic`：将 batch 组成字典（images, boxes, small_boxes, masks, img_names, small_box_corners），供 Trainer 使用。 |

### 2.4 utils/（Prompt、指标、可视化）

| 路径 | 内容 |
|------|------|
| `utils/prompts.py` | `prepare_box_prompts(big_box, small_box, device)`：将大框与小框（AABB）堆叠为 (N,4) tensor，供 SAM prompt_encoder 使用。 |
| `utils/metrics.py` | `compute_miou`、`compute_iou_per_sample`（逐样本 IoU）、`mask_entropy_logits`（二分类熵，用于熵筛选）。 |
| `utils/visualization.py` | 预测与框的可视化（如 `visualize_prediction_with_boxes`，用于 poor sample 检测）。 |
| `utils/training_utils.py` | set_seed、mkdir、setup_cuda_memory 等。 |
| `utils/test/generate_oriented_boxes.py` | 从大框生成旋转小框并写入 CSV。 |
| `utils/test/validate_small_boxes.py` | 验证小框是否在前景内，并做简单统计与可视化。 |

## 三、关键代码位置速查

| 需求 | 位置 |
|------|------|
| 修改/增加命令行参数 | `config/args.py` |
| 修改数据加载与 batch 结构 | `dataset/ISIC.py`、`training/data_utils.py` |
| 修改 Teacher/Student 前向或解冻策略 | `training/trainer.py`（_teacher_forward, _student_forward）、`models/sam_wrapper.py` |
| 修改 SAM 的 box prompt 组成 | `utils/prompts.py` 的 `prepare_box_prompts`；调用处在 trainer 的 _teacher_forward、_student_forward、_student_decoder_forward_for_dice |
| 修改正负样本定义与采样 | `training/trainer.py` 的 `_compute_contrastive_loss`（约 672–1150 行） |
| 修改自适应权重（交集/并集/困难） | `training/trainer.py` 的 `_get_adaptive_weights` |
| 修改损失权重或新增损失 | `training/trainer.py` 的 `_compute_losses`；损失实现见 `models/losses.py` |
| 修改 EMA 策略 | `training/trainer.py` 的 `_update_ema_teacher`、`_get_ema_decay` |
| 早停与 best checkpoint | `training/trainer.py` 的 `train()` 内 epoch 循环末尾 |
| 表现差样本检测与保存 | `training/trainer.py` 的 `_detect_and_save_poor_samples`、`_save_poor_samples_csv` |
| 旋转小框 → mask | `training/trainer.py` 的 `_create_box_mask_from_corners`；角点来自 batch 的 `small_box_corners` |

## 四、建议阅读顺序

1. **跑通流程**：`train.py` → `config/args.py`（了解参数）→ `Trainer.__init__` 与 `Trainer.train()` 的 batch 循环（了解主流程）。
2. **数据流**：`dataset/ISIC.py` 的 `__getitem__`（返回 6 元组）→ `data_utils.collate_fn_isic` → `_prepare_images_and_boxes`（坐标缩放）。
3. **前向与损失**：`_teacher_forward`（prompt 与熵）→ `_student_forward`（encoder + 冻结 decoder）→ `_compute_losses`（各 loss 是否反传）→ `_compute_contrastive_loss`（正负样本与 InfoNCE）。
4. **对比学习细节**：`_compute_contrastive_loss` 内：熵筛选 → 大小框/过渡区 mask → 正负样本类型与权重 → 均衡 → `pixel_info_nce`（在 `models/losses.py`）。
5. **模型与优化**：`models/sam_wrapper.py`（加载与 Teacher 创建）→ `models/projection.py`（PixelProjHead）→ `_setup_optimizer`、`_update_ema_teacher`。

按上述顺序阅读即可在尽量少跳转的情况下理解「数据 → Teacher/Student → 损失 → 优化」的完整链路。
