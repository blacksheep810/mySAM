## 一、项目概述与目标

### 1.1 任务目标

在**仅使用框提示（box prompt）、GT mask 不参与反传**的前提下，通过**像素级对比学习 + 特征蒸馏**微调 SAM 的 image encoder，提升 ISIC2016 皮肤病灶分割的 mIOU。训练信号来自对比损失和蒸馏损失；mask_loss / iou_loss / mIOU 仅作监控和早停依据。

### 1.2 核心架构

```
数据: ISIC 图像 + 大框 + 小框(旋转/轴对齐) + GT mask(仅监控)

Teacher (EMA) ──大框+小框(AABB)──► 伪标签 mask_logits
         │
         ▼
Student encoder (可训练) ──► img_emb ──► proj ──► 对比学习
         │
         └── decoder (冻结) ──► pred_logits (仅监控 mIOU)

训练信号: contrastive loss + distill loss [+ pseudo_dice_loss]
监控指标: avg_mIOU, avg_mask_loss, avg_iou_loss, TS一致性
```

### 1.3 技术要点

- **Teacher-Student**：EMA 更新的 Teacher 生成伪标签，Student 学习与其对齐。
- **双框约束**：小框内一定是前景，大框外一定是背景；小框可为旋转框（角点）或轴对齐 AABB。
- **SAM Prompt**：Decoder 仅支持 AABB，故传入**大框 + 小框外接正交框**；对比学习阶段使用**旋转小框多边形 mask** 做精确采样。
- **像素级 InfoNCE**：anchor 为正样本像素，positive 为 Teacher 同位置特征，negatives 为困难负样本 + in-batch negatives。
- **过渡区域采样**：大框内、小框外的边界区域提高采样密度，强化边界判别。

## 三、数据准备与细节操作

### 3.1 ISIC 目录结构

```
data/ISIC/
├── train_boxes.csv            # 至少含：image_file, mask_file, max_boxes_x1/y1/x2/y2
├── train_boxes_update.csv     # 含 small_box 角点或 min_boxes_*
├── test_boxes.csv
├── ISBI2016_ISIC_Part1_Training_Data/   # 训练图像
└── ISBI2016_ISIC_Part1_Training_GroundTruth/  # 训练 mask
```

- **train_boxes.csv**：大框坐标，可由 ISIC_deal 或标注工具生成。
- **train_boxes_update.csv**：在 train_boxes 基础上增加小框。小框可为轴对齐（min_boxes_x1/y1/x2/y2）或旋转角点（small_box_corner1_x/y … small_box_corner4_x/y），由 `generate_oriented_boxes.py` 生成。

### 3.2 生成旋转小框（generate_oriented_boxes.py）

- **功能**：从大框内缩生成小框，并按病灶方向旋转。
- **用法**：
  ```bash
  python utils/test/generate_oriented_boxes.py \
    --data_root /path/to/ISIC --output_root /path/to/update_ISIC \
    --auto_adapt --no_strict
  ```
- **关键参数**：`--no_strict` 放宽约束得到更大小框；`--auto_adapt` 自动搜索内缩比例；否则用固定 `--shrink_ratio`。

### 3.3 验证小框（validate_small_boxes.py）

```bash
python utils/test/validate_small_boxes.py \
  --data_root ./data/ISIC --csv_path ./data/ISIC/train_boxes_update.csv \
  [--output_dir ./box_validation] [--threshold 0.9]
```

输出：统计与不合格样本可视化，用于检查小框是否基本处于前景内。

## 四、训练流程与单步详解

### 4.1 单 Step 流程

1. **数据**：batch 含 image、boxes、small_boxes、mask、small_box_corners（可选）。
2. **预处理**：图像 resize 到 1024×1024，框坐标按比例缩放；若启用 `--student_strong_aug`，对 Student 输入做强颜色增强。
3. **Teacher 前向**：大框+小框(AABB) prompt → mask_logits，计算熵。
4. **Student 前向**：encoder 可训练，decoder 冻结；得到 `img_emb`、`pred_logits`；若 `pseudo_dice_weight>0`，另用 `img_emb` 经 decoder 得到 `pred_for_dice` 与 Teacher 伪标签算 Dice。当前代码支持进一步叠加 `pseudo_dice_use_confidence_mask` 与 `pseudo_dice_boundary_weighted`，让 pseudo Dice 更聚焦高置信与边界区域。
5. **熵筛选**：仅 avg_entropy ≤ entropy_thresh 的样本参与对比学习。
6. **正负样本构建**：基于大小框（及旋转 `small_box_mask`）、Teacher/Student 预测、过渡区域，构建正负 mask。若启用 `hard_sample_use_disagreement`，则按 `hardness = alpha * |p_t-p_s| + beta * entropy_t` 对候选困难样本做 top-k 采样。
7. **损失**：loss_contrast（反传）、loss_distill（反传）、loss_dice_pseudo（若启用，反传）；loss_mask、loss_iou、batch_miou 仅监控。
8. **优化**：backward 更新 encoder + proj；EMA 更新 Teacher。当前支持固定慢 EMA（`ema_fixed_decay`）与间隔更新（`ema_update_interval`），用于缓解 TS 一致性过高。`best_checkpoint` 与早停优先基于验证集 `val_mIOU`，不再基于训练集 `avg_mIOU`。

### 4.2 训练输出与日志指标

| 指标 | 含义 |
|------|------|
| avg_mask_loss | Student 预测与 GT 的 BCE+Dice（仅监控） |
| avg_contrast | 像素对比损失（主要训练信号） |
| avg_iou_loss | pred_iou 与 gt_iou 的 MSE（仅监控） |
| avg_mIOU | 与 GT 的 mean IoU（监控 + 早停/保存 best） |
| TS一致性 | 大框区域内 Teacher 与 Student 前景 mask 的 IoU（Box-FgIoU） |
| avg_dice_pseudo | 伪标签 Dice 损失（若启用） |

输出文件：`checkpoint_epoch_N.pth`、`best_checkpoint.pth`（需 `--save_best_ckpt`）；若 `--detect_poor_samples` 则生成 `poor_samples_epoch_*/`。

## 五、对比学习正负样本策略

### 5.1 核心原则

- **伪标签置信度筛选**：仅处理 Teacher 平均熵 ≤ `entropy_thresh`（默认 0.2）的样本。
- **大小框约束**：正样本必须在小框内（或过渡区内且满足条件）；负样本包含小框内预测为背景（漏检）、大框外预测为前景（溢出）。
- **旋转小框**：对比学习阶段用 `small_box_corners_list` 生成旋转多边形 `small_box_mask`，保证内部正样本 100% 前景；SAM 的 prompt 仍用 AABB。

### 5.2 正样本类型（概要）

| 类型 | 条件 | 权重/说明 |
|------|------|-----------|
| 交集正样本 | 小框内且 Teacher 和 Student 都预测前景 | 高权重，训练初期主用 |
| 并集正样本 | 小框内且 Teacher 或 Student 预测前景（排除交集） | 训练中期引入 |
| 困难正样本 | 小框内 Teacher 前景、Student 背景 | 中后期引入，强化学习 |
| Student 主导正样本 | 小框内 Student 前景、Teacher 背景 | 小框内必为前景，Student 对、Teacher 错，应保留 |
| 过渡区域正样本 | 大框内小框外且 Teacher 预测前景 | 需 `--transition_region_enabled`，强化边界 |

### 5.3 负样本类型（概要）

| 类型 | 条件 |
|------|------|
| 小框内漏检 | 小框内且 Teacher/Student 预测背景（交集/并集） |
| 大框外溢出 | 大框外且预测前景（交集/并集） |
| 困难负样本 | 大框外且 Student 前景、Teacher 背景（需纠正）；带置信度过滤与数量上限 |

### 5.4 自适应权重与过渡区参数

- 权重随训练进度（epoch 占比）与 mIOU/TS 一致性动态调整；困难负样本有权重上限与 mIOU/TS 保护。
- 若启用 `--hard_sample_use_disagreement`，正样本与困难负样本会优先从高分歧、高熵位置采样，而不是纯随机均匀采样。
- 过渡区域：`--transition_region_enabled`、`--transition_region_sampling_ratio`（默认 1.5）、`--transition_region_min_confidence`（默认 0.6）、`--transition_region_max_ratio`（默认 0.3）。

## 六、正负样本平衡与风险

### 6.1 样本数量统计与均衡

- 每个 batch/epoch 统计正负样本数与正负比例；目标比例由 `--pos_neg_ratio`（默认 0.25，即 1:4）控制。
- 当比例失衡时（如正过多或负过多），代码内会通过增删负样本尽量靠近目标比例。

### 6.2 风险与保护

- **正样本全错/负样本全错**：会导致对比学习失效或反向优化。当前保护：正样本为空则跳过该 batch；负样本为空则返回 0 损失。
- **正负严重失衡**：有自动均衡机制；仍建议关注日志中的正负比例与失衡警告。
- **正样本过少**：训练初期交集正样本可能很少，导致部分 batch 被跳过；可适当放宽熵阈值或检查小框/Teacher 质量。
- **小框方向错误**：若旋转小框标反，正样本可能取到背景。代码有 AABB 回退；建议用 `validate_small_boxes.py` 抽检。

### 6.3 建议改进（可选）

- 增加正样本置信度检查与批量跳过统计/告警。
- 负样本池为空时的回退策略可加强质量约束。
- 见下文「可选改进建议」一节。

## 七、表现差样本检测

### 7.1 功能说明

在训练过程中**实时**识别 mIOU 表现差的样本，保存可视化和 CSV，便于分析数据质量与模型薄弱点。

### 7.2 使用方法

训练时添加参数：

```bash
--detect_poor_samples \
--poor_sample_iou_threshold_severe 0.75 \   # IoU < 0.75 为严重
--poor_sample_iou_threshold_moderate 0.8 \  # 0.75 ≤ IoU < 0.8 为中等
--poor_sample_save_interval 1
```

或使用脚本：`bash train_with_poor_detection.sh`。

### 7.3 输出结构

```
output_dir/
├── poor_samples_epoch_1/
│   └── visualization/
│       ├── severe/    # IoU < 0.75
│       └── moderate/  # 0.75 ≤ IoU < 0.8
├── poor_samples_epoch_2/ ...
└── poor_samples_csv/
    ├── poor_samples_all_epochs.csv
    └── poor_samples_epoch_*.csv
```

可视化包含：原图、大框（红）、小框（绿）、预测 mask（绿半透明）、GT（蓝轮廓）、IoU 与文件名。

## 八、损失与梯度、mIOU 不提升原因

### 8.1 损失与梯度

| 损失项 | 是否反传 | 梯度去向 |
|--------|----------|----------|
| loss_mask | 否 | 仅监控 |
| loss_iou | 否（pred_iou 无梯度） | 仅监控 |
| loss_contrast | 是 | proj + encoder |
| loss_distill | 是 | encoder |
| loss_dice_pseudo | 是（若启用） | encoder |

因此，**真正更新 encoder 的只有 contrastive + distill（+ pseudo_dice）**；`mask_loss` / `iou_loss` / `avg_mIOU` 仅用于监控，不再混入总训练损失。当前 `distill` 已修复为 **Student feature 对齐 Teacher feature**，而非 student 对齐自身快照。

### 8.2 导致“间接提升”变弱的因素

| 因素 | 说明 | 对策 |
|------|------|------|
| 小框 prompt | 曾仅用大框 | ✅ 已修复，恢复大框+小框 AABB |
| EMA 策略 | 动态 0.97→0.998，Teacher 跟过快 | 可改为更保守（如 0.999） |
| TS 一致性过高 | ≈0.9998，困难样本少 | 降低 EMA 或放宽熵阈值；已通过强增强+伪 Dice 缓解 |
| 早停过早 | patience=5 | 增大 `--early_stop_patience`（如 10） |
| 小框质量 | 旋转框过小/噪 | 用 `--no_strict` 或 GT 内接矩形 |
| 学习率 | lr_encoder 较小 | 可适当提高到 1e-5 或增大 unfreeze_last_k |

## 九、已实施改进与发刊视角

### 9.1 修复 SAM Prompt 与旋转小框利用

- **Prompt**：Teacher/Student 均使用 `[big_box, small_box]`，其中 small_box 为旋转小框的**外接 AABB**（SAM 仅支持 AABB）。
- **对比学习**：使用 `small_box_corners_list` 生成**旋转多边形 mask**，正负样本严格约束在该多边形内/外，保证内部正样本为纯前景。
- **发刊**：可表述为「旋转双框空间约束」+「AABB 兼容 SAM、旋转 Mask 保证采样纯度」的混合策略。

### 9.2 Student 强数据增强

- **内容**：`--student_strong_aug` 对 Student 输入做强颜色抖动，Teacher 用原图。
- **作用**：降低 TS 一致性过高（特征坍缩），迫使 Student 学鲁棒特征。
- **发刊**：Asymmetric Contrastive Learning / Perturbation-Invariant Representation Learning。

### 9.3 伪标签 Dice 辅助损失

- **内容**：`--pseudo_dice_weight`，Student 用当前 img_emb 经 decoder 得到 mask 与 Teacher 伪标签算 Dice，梯度回传 encoder。
- **作用**：提供稠密空间监督，弥补仅点级对比对 mIOU 驱动不足。
- **发刊**：表示与生成对齐（Alignment between Representation and Generation）。

### 9.4 Pseudo Dice 强化

- **内容**：代码已支持 `--pseudo_dice_use_confidence_mask`、`--pseudo_dice_confidence_thresh`、`--pseudo_dice_boundary_weighted`、`--pseudo_dice_boundary_alpha`。
- **作用**：只在 Teacher 高置信区域计算 pseudo Dice，并对高熵边界区、Teacher/Student disagreement 区提高权重，避免全图平滑对齐导致边界学不动。
- **发刊**：可表述为 Boundary-aware Pseudo Mask Alignment。

### 9.5 Teacher 慢更新与分歧驱动困难样本

- **内容**：代码已支持固定慢 EMA `--ema_fixed_decay`、间隔更新 `--ema_update_interval`，以及分歧驱动困难样本 `--hard_sample_use_disagreement`、`--hardness_alpha`、`--hardness_beta`。
- **作用**：人为保留 Teacher/Student 的可学习差异，并把训练资源优先放在高分歧、高不确定区域。
- **发刊**：可表述为 Disagreement-aware Hard Pixel Mining + Slow-moving Teacher。

### 9.6 已修复的关键逻辑问题

- **真实蒸馏**：`loss_distill` 现已使用 `teacher.image_encoder` 输出特征，不再是 Student 对齐自身。
- **验证闭环**：若提供 `--test_box_csv`，训练阶段会构建验证集 loader，用 `val_mIOU` 保存 `best_checkpoint.pth` 并执行早停。
- **TS 一致性修正**：由原来的“全图像素一致率”改为“大框区域前景 IoU（Box-FgIoU）”，更贴近分割质量。
- **困难样本消融更干净**：`hard_sample_use_disagreement` 主要作用于 hard region，不再默认改变全部普通正样本的采样分布。
- **teacher 特征复用**：对比学习正样本直接复用同 batch 的 teacher embedding，避免重复编码，提升实验吞吐。

## 十、可选改进建议与备选方向

### 10.1 若希望 mIOU 随训练明显提升

1. **让 mask 相关损失参与反传**（需改设计）：去掉 pred 的 no_grad/detach，使梯度经冻结 decoder 回传 encoder；需注意稳定性与过拟合。
2. **加强对比与蒸馏**：提高 lr_encoder、unfreeze_last_k，或调整对比/蒸馏权重。
3. **数据与样本**：检查小框、过渡区、困难样本权重；用验证集 mIOU 做早停与 save_best。

### 10.2 备选：轻量级解冻 Decoder (PEFT)

若 mIOU 在 0.77 附近瓶颈，可考虑在 Decoder 上做极少量 PEFT（如 LoRA/Adapter），并包装为「解耦适应框架」：Encoder 对比学习解决 domain shift，Decoder 少量参数注入医学先验。注意：会稀释「纯表示学习」的故事，需在消融中说明收益来源。

### 10.3 备选：基于熵的困难样本挖掘

利用 Teacher 预测熵，将高熵区域（模糊边界）作为极难负样本并提高权重，强化边界学习。

### 10.4 像素级对比学习文献对应

本项目属弱监督（框+伪标签）+ Teacher-Student + 困难样本 + 过渡区采样。可与 PixContrast/PixPro（同像素不同视图）、全监督同类别/困难负样本（如 Contextrast BANE）、PNE 正负等权等工作对照，便于写相关工作。

## 十二、平台期后的实验优先级与消融计划

> 项目已过「能不能跑起来」阶段，进入**平台期后的研究优化阶段**。当前已做的两件事——Student 强颜色增强（打破 TS 过强同质性）、pseudo dice loss（给 encoder 更直接的空间监督）——都在解决同一核心问题：**训练信号太“表示层”，对最终 mask 质量的驱动不够直接。** 下一步不建议盲目加新 loss，而应按以下优先级推进。

---

### 12.1 第一优先级：让 mask 分支对 encoder 的约束再强一点

目标：让 **mIoU 的提升路径更直接**，而不是只靠 contrastive/distill 间接带动。

#### 方向 A：增强 pseudo dice 分支

已加 pseudo dice 后，重点不是「有没有加」，而是：

- `pseudo_dice_weight` 是否太小；
- pseudo dice 是否只在 teacher 已经很自信的区域起作用；
- pseudo 标签是否过于平滑，导致 student 学不到边界。

**建议实验：**

1. **系统扫 `pseudo_dice_weight`**  
   做小规模消融：`0.05, 0.1, 0.2, 0.3, 0.5`。观察：avg_mIoU、TS consistency、avg_dice_pseudo、边界质量。很多时候是**权重没到有效区间**。

2. **对 pseudo dice 加置信度 mask**  
   不要全图都算，只在 teacher 较可信区域算：小框内高置信→强监督；过渡区→弱监督或不参与；大框外 teacher 高置信背景→背景监督。这样比全图对齐更稳。

3. **边界加权 dice / focal dice**  
   瓶颈常在边界。可让过渡区、高熵边界区、teacher/student disagreement 区权重更高，比继续加普通对比损失更有效。

---

### 12.2 第二优先级：调整 teacher 更新策略，制造「可学习差异」

文档中已指出：**TS 一致性≈0.9998，困难样本太少**，说明 teacher 跟 student 太近。除 Student 强增强外，可从 **teacher 端** 继续下手。

| 建议 | 做法 |
|------|------|
| **EMA 更慢** | 当前动态 0.97→0.998 易让 teacher 中后期跟得太紧。建议直接试：固定 `ema=0.999` 或 `ema=0.9995`，让 teacher 更像「稳定目标」，不要和 student 同步收敛到太相似状态。 |
| **Test-time stable teacher** | Teacher 输入保持更干净、稳定（完全不增强、更稳定标准化），Student 继续强增强（颜色 + 少量模糊/噪声），使 teacher/student 特征分布形成有意义的蒸馏差。（当前已部分做到，可进一步强化。） |
| **阶段性冻结 teacher** | 每 N step 更新一次 EMA，或每个 epoch 只更新一次 teacher，进一步避免二者高度同步。 |

---

### 12.3 第三优先级：困难样本挖掘升级（置信度/不一致性驱动）

论文价值高的是：**在弱监督 box 条件下，如何构造高质量 pixel-level hard samples**。  
现有：小框内困难正样本、大框外困难负样本、过渡区采样。下一步建议从「空间规则驱动」升级到「**置信度/不一致性驱动**」。

**推荐：基于 disagreement map 的困难样本采样**

- **teacher 前景、student 背景** → hard positive  
- **teacher 背景、student 前景** → hard negative  
- **teacher/student 都不确定（高熵）** → boundary-hard region  

采样时提高这些区域的概率，而非均匀采样。困难度可定义为：

$$hardness = \alpha \cdot |p_t - p_s| + \beta \cdot \text{entropy}_t$$

其中 `|p_t - p_s|` 为 TS 分歧，`entropy_t` 为 teacher 不确定性。按 hardness 做 top-k 或加权采样。  
优点：直接提升训练信号质量、易写成论文贡献、比单纯调学习率更有研究味道。

---

### 12.4 第四优先级：增强 encoder 可学习能力

若仍是 `lr_encoder=2e-6`、`unfreeze_last_k=0` 或很小，平台期属正常——用很弱的参数更新推动较大的 domain adaptation。

**建议组合：**

- 方案 1：`lr_encoder=5e-6`，`unfreeze_last_k=3`
- 方案 2：`lr_encoder=1e-5`，`unfreeze_last_k=3` 或 `4`
- 方案 3（分层学习率）：靠近输出端 block 用较大 lr（如 `1e-5`），更前 block 用较小 lr（如 `3e-6`）

不改 decoder 的前提下，这是最直接增强模型适应能力的方式。

---

### 12.5 第五优先级：轻量级 decoder 适配（备选）

若前述都做了，mIoU 仍卡在 0.77~0.79，说明**单靠 encoder 表示迁移快到上限**。此时可考虑极轻量 decoder PEFT：LoRA、Adapter、或只解冻 decoder 中极少量参数。  
注意：会稀释「纯 encoder 弱监督表示学习」的故事，建议作为主线做完后的备选实验或论文中的增强版消融。

---

### 12.6 第六优先级：边界监督

若主体区域已分得差不多、边界一直粗糙、mIoU 难再升，可专门做边界学习：

1. **边界区域重加权**：GT 边界附近或 teacher 高熵边界附近提高损失权重。  
2. **Boundary contrast**：把边界内外像素当作 hardest positive/negative 做对比。  
3. **Boundary-aware pseudo loss**：对 pseudo label 提边界，再做边界 BCE/Dice 辅助项。  

可视化若发现主体尚可、边缘糊，这条路线会较有效。

---

### 12.7 当前代码已支持的 4 组实验开关

下面四组实验已可直接通过参数组合运行：

1. **pseudo dice 强化**
   `--pseudo_dice_weight 0.05/0.1/0.2/0.3/0.5`
   可叠加：`--pseudo_dice_use_confidence_mask --pseudo_dice_boundary_weighted`

2. **teacher 变慢**
   `--ema_fixed_decay 0.999`
   或 `--ema_fixed_decay 0.9995`
   若想进一步冻结：`--ema_update_interval 5` 或更大

3. **hard sample 升级**
   `--hard_sample_use_disagreement --hardness_alpha 0.5 --hardness_beta 0.5`

4. **增强 encoder 更新**
   `--lr_encoder 5e-6 --unfreeze_last_k 3`
   或 `--lr_encoder 1e-5 --unfreeze_last_k 3`

### 12.8 建议优先做的 4 组实验（不同时改太多）

| 实验组 | 内容 | 观察指标 |
|--------|------|----------|
| **1. pseudo dice 强化** | 扫 `pseudo_dice_weight = [0.05, 0.1, 0.2, 0.3, 0.5]`，建议叠加置信度 mask 与边界加权 | mIoU、边界质量、TS consistency |
| **2. teacher 变慢** | 固定 `ema=0.999` 或 `0.9995`，必要时再加间隔更新 | 困难样本比例是否回升 |
| **3. hard sample 升级** | 用 `\|p_t-p_s\| + entropy_t` 做困难样本采样 | 对比当前基于规则的困难样本 |
| **4. 增强 encoder** | `lr_encoder=5e-6, unfreeze_last_k=3` 或 `lr_encoder=1e-5, unfreeze_last_k=3` | mIoU、收敛速度 |

这四组比「再加一个新损失」更值得做。

### 12.9 发刊视角：下一步主线故事

适合收敛的表述：

> **在 box-only 弱监督条件下，利用旋转双框空间约束 + teacher-student disagreement-aware hard pixel mining + pseudo mask alignment，实现对 SAM encoder 的稳定领域适配。**

即：下一步最值得强化的是——

1. **困难样本挖掘更智能**（disagreement + 熵）
2. **pseudo supervision 更边界友好**（置信度 mask、边界加权）
3. **teacher/student 差异控制更合理**（慢 EMA、阶段性冻结）

而不是「多一个 loss」。
